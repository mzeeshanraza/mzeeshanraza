I have **4+ years** of experience building web applications that run in production and are used by real customers — not just prototypes. My work usually covers the whole lifecycle: schema design, API contracts, frontend integration, deployment, caching and performance tuning.

- 🏗️ Built a **custom learning platform** handling payments, enrollment flows, progress tracking and reporting dashboards

- ⚡ Cut page load and server cost through **Redis caching, CDN configuration and query optimisation**
- ☁️ Own my own infrastructure — **AWS Lightsail, CloudFront, Cloudflare, S3, Nginx, PM2**
- 🔌 Comfortable integrating third-party APIs, webhooks and background jobs into existing systems

---

### How I Work

- **Contracts first** — API shape and data model settled before the first line of UI
- **Boundaries matter** — layers stay separate so features can be replaced, not patched around
- **Measure, then optimise** — cache hit rate, query count and TTFB over guesswork
- **Ship maintainable** — small PRs, documented decisions, no clever code without a reason
